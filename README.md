# SA_WEF_data

This repository contains the code used for preparing a dataset on household-level water, energy and food (WEF) security for South Africa. The data covers the whole country (scale) at the municipal level (resolution). The resulting datasets, along with intermediary datasets, have been published on the South African Environment Observatory Network's (SAEON) data portal: https://doi.org/10.15493/SARVA.42092023. The data preparation is described in the metadata accompanying the datasets, and further explained in the manuscript resulting from this work, titled: "A framework for spatially quantifying household-level Water-Energy-Food security: application to South Africa" (submitted). This work is part of a research project on spatial inequality in Water-Energy-Food security in South Africa, the implications for public health and the impacts of climate change (for the project website, see here: https://sarva.saeon.ac.za/wefh-nexus/).
